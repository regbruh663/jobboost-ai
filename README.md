# JobBoost AI

A free, zero-API-cost job application toolkit that runs entirely in the browser.

## What it does
- Accepts a job title and job description
- Accepts the user's experience/skills
- Generates resume bullets
- Generates a cover letter
- Generates interview questions and guidance
- Requires no paid API and no backend

## Put it on GitHub Pages for free

1. Create a public GitHub repository named `jobboost-ai`.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. In GitHub, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the public site address.

## Monetization path

The MVP itself is free. To make money, add a monetization layer after traffic exists:
- Legitimate affiliate programs for career/job-search products
- A premium application package
- Resume-review service
- Sponsored placement from relevant career products

Do not promise users guaranteed jobs or guaranteed income.

## Important

This is intentionally a no-API MVP. The "AI" branding describes the product concept; the current generator uses browser-side templates and keyword extraction so there is no API bill.
